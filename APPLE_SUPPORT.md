# XFiles Pro Support

XFiles Pro is a local-first file manager for iPhone and iPad. It supports local files and optional FTP, FTPS, SFTP, WebDAV, SMB, Google Drive, Jellyfin, and Emby network locations. XFiles Pro also unlocks an SSH terminal for SFTP locations.

## Contact

Email: [nearby@local1st.app](mailto:nearby@local1st.app)

When reporting a problem, include the XFiles version, iOS or iPadOS version, device model, connection type, and the exact error message. Never send passwords, private keys, OAuth tokens, or confidential files.

## Purchases and subscriptions

- To restore an eligible purchase, open **Settings → XFiles Pro → Restore Purchases**.
- To manage or cancel a subscription, open **Settings → XFiles Pro → Manage Subscription**.
- Apple processes payments and refunds. For billing or refund requests, use [reportaproblem.apple.com](https://reportaproblem.apple.com/).
- A canceled subscription remains active until the end of its paid period. A lifetime unlock is a one-time, non-consumable purchase.

## Network connection help

- Confirm the host, port, username, authentication method, and initial path with the server administrator.
- For SFTP and SSH Terminal, verify that the server permits both SFTP and interactive SSH for the same account.
- XFiles connects directly from your device to the server or cloud service you configure; there is no XFiles relay server.
- Removing a saved Network Location deletes its locally stored connection details from XFiles.
